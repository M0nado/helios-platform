# XCore9 runtime smoke evidence

This directory is reserved for generated runtime smoke evidence:

- `local-windows-smoke.{md,json}`
- `local-docker-smoke.{md,json}`
- `hybrid-windows-docker-fleet-smoke.{md,json}`

These files are generated by `Invoke-XCore9RuntimeMatrixSmoke.ps1` and uploaded by
`.github/workflows/xcore9-runtime-matrix-validate.yml` as CI artifacts.
They are intentionally excluded from Git to avoid committing run-specific evidence.
